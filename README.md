# Petocalypse
Pet + Apocalypse라는 뜻의 펫토칼립스는, 아포칼립스 세계에 떨어진 동물이 반려인간을 구하러 가는 게임입니다.<br/>
다양한 동물이 되어 몬스터를 물리치고 주인을 무사히 구출하세요!

## 게임 소개

- **엔진 :** Unity 2022.3.62f3
- **개발 기간 :** 2026.01.08 ~ 2026.05.31 (약 5개월)

### 게임 규칙


#### 핵심 게임 루프

1. 플레이어는 자동 소환되는 **몬스터**를 잡으며 **경험치**를 모음.
2. 경험치를 모아 레벨업을 할 때마다 **스킬을 하나 선택해 강화** 가능.
3. 몬스터를 잡아서 능력치를 올리다가, 제한 시간 내에 **보스방에 입장**해야 함.
4. 보스를 잡으면 **클리어 성공**.
5. 몬스터/보스에게 죽거나, 제한 시간 내에 클리어하지 못하면 **클리어 실패**.


#### 조작 방식

  - **가상 조이패드**로 캐릭터 이동.
  - 캐릭터는 가장 가까운 몬스터를 조준해 **자동 공격**.
  - 캐릭터 이동에 따라 **카메라 추적**.


#### 적 시스템

  - 플레이어가 적에 **몸박** 시 HP가 깎임.
  - 몬스터를 처치하면 **`경험치`** / **`아이템`** / **`골드`** 를 드랍.
  - 일정 시간마다 **웨이브 단계**가 올라가고, 몬스터가 더 많이 소환됨.
  - **근접** 공격과 **원거리** 공격 몬스터로 나뉨.


#### 성장 시스템

  - 영구 스탯
  - 게임 플레이 중 얻은 골드를 사용해 훈련소에서 스탯 강화.
  - 훈련소에서 올린 스탯은 영구 지속됨.
    
  - 게임 내 스탯
  - 레벨업 시 원하는 스킬을 선택해 강화함.
  - 스킬을 강화하면 능력치가 강해지고 추가 능력이 발현됨.
  - 강화한 스킬들은 스테이지가 끝나면 초기화됨.

## 주요 기능
### Core Game
- 가상 조이패드 기반 플레이어 이동
- 가장 가까운 몬스터를 대상으로 한 자동 공격
- 경험치 획득 및 레벨업 시스템
- 몬스터 피격 시 플레이어 체력 감소
- 플레이어 사망 및 게임 오버 처리
- 화면 밖 랜덤 위치에서 몬스터 자동 생성
- 몬스터 자동 이동 및 체력 감소 처리
- 몬스터 사망 시 경험치 드랍

### System
- 스테이지 시작/종료 및 게임 타이머 관리
- 몬스터, 투사체, 경험치 등 오브젝트 풀링을 통한 성능 최적화
- 플레이어/몬스터 인스턴스 관리 및 데이터 파싱
- 몬스터 기본 스탯 데이터 관리

### UI & OUT GAME
- BackGround MAP, HP바, 경험치바, 킬 수, 타이머 HUD 표시
- 게임 오버 팝업 및 재시작/메인 이동 버튼
- 레벨업 시 랜덤 스킬 3개 선택 팝업
- 로비 메인 화면 및 게임 시작
- 훈련소 제작 및 데이터 저장
